1.1.1Architecture of the CPU

The CPU (Central Processing Unit) processes data by repeatedly fetching, decoding and executing instructions. It is the "brain" of the computer.

What is inside the CPU

Von Neumann architecture: instructions and data are stored together in the same main memory (RAM). The CPU fetches them one after another, using a single processor and the registers above.

The components

ALU

CU
Control Unit		Controls the fetch-decode-execute cycle, decodes instructions and directs data around the CPU.
CacheVery fast memory in or next to the CPU, holding frequently used data and instructions.

1.1.1Registers in depth

A register is a tiny, extremely fast storage location inside the CPU. Each of the four you need to know holds just one thing at a time, and what it holds keeps changing as the fetch-decode-execute cycle runs.

The letters give the job away. In MAR, the A is for Address. In MDR, the D is for Data. The PC counts its way through the program, so it knows what comes next. The ACC accumulates, so it keeps the answer.

A story to remember them

You are the CPU, following a list of instructions kept in a huge library (RAM).

  • The PC is your bookmark. It says which item on the list comes next.
  • You write that shelf number on a slip of paper. That slip is the MAR.
  • The librarian finds the item and puts it on a tray. That tray is the MDR.
  • You read it and do the sum. You write the answer on your notepad. That notepad is the ACC.

Follow the data

The numbers show the order things happen in during one cycle.

StepWhat happensRegisters used
1The address of the next instruction is copied from the PC to the MAR. The PC is then increased by 1.PC, MAR
2The address in the MAR tells RAM where to look.MAR
3The instruction at that address is copied from RAM into the MDR.MDR
4The Control Unit decodes the instruction held in the MDR.MDR
5The instruction is executed. If it needs a calculation, the ALU does it.
6The result of the calculation is stored in the ACC.ACC

Mistakes that lose marks

  • The PC holds the address of the next instruction, not the one being run. It has already moved on by the time execution starts.
  • The MAR holds an address. It never holds the instruction or data itself. That is the MDR's job.
  • The MDR can hold data or an instruction, and it works in both directions (reading and writing).
  • The ACC holds results from the ALU. It is not where things arrive from RAM.
  • Saying what the letters stand for is not enough. Always say what the register holds.

1.1.2CPU performance

Three factors affect how fast a CPU performs. For each one, learn what it is and why it makes the computer faster.

FactorWhat it isEffect on performance
Clock speedMeasured in GHz. The number of fetch-decode-execute cycles per second. 3 GHz is 3 billion cycles a second.Higher clock speed means more instructions processed per second. The downside is that the CPU gets hotter.
Cache sizeFast memory on or next to the CPU. Much faster than RAM but expensive, so it is small.A larger cache means frequently used data is close by, so the CPU waits for RAM less often.
Number of coresEach core is effectively a separate processor that can run its own fetch-decode-execute cycle.More cores means more instructions processed at the same time, which helps with multitasking.

Exam trap: more cores does not always mean faster. The software must be written to split its work across the cores (parallel processing). A program that does one task at a time will not speed up much, however many cores there are.

1.1.3Embedded systems

Definition: an embedded system is a computer system built into a larger device to perform a dedicated (specific) function.

Typical characteristics

  • Does one specific task (or a small number), unlike a general-purpose computer.
  • The program is stored in ROM (firmware), so it is not easily changed.
  • Usually small, low power and cheap.
  • Often works in real time, responding instantly (for example a car airbag).
  • Often has a limited or no user interface.

Examples: washing machine, microwave, digital watch, car engine management system, traffic lights, central heating thermostat, TV remote, smart doorbell, pacemaker.

1.2Memory and storage

1.2.1 Primary storage (memory)

Primary storage is memory the CPU can access directly. The CPU needs it because it can only work on data and instructions that are in main memory, not on a hard drive.

RAMROM
Stands forRandom Access MemoryRead Only Memory
Volatile?Volatile: contents are lost when power is offNon-volatile: contents stay when power is off
Read / writeCan be read and writtenCan only be read (not normally changed)
PurposeHolds the programs, data and parts of the operating system currently in useHolds the bootstrap (start-up instructions) that load the operating system when the computer is switched on

Virtual memory: when RAM is full, the computer uses part of the secondary storage as if it were extra RAM. Data not needed right now is moved out of RAM into virtual memory, and moved back when needed. This lets more programs run, but it is slower because secondary storage is slower than RAM.

1.2.2 Secondary storage

Secondary storage is needed because RAM is volatile and limited. It is non-volatile, so it keeps programs and files when the power is off, and it holds much more data.

TypeExamplesStrengthsWeaknesses
MagneticHard disk drive (HDD)Large capacity, cheap per GBSlower, moving parts so less durable, uses more power
OpticalCD, DVD, Blu-rayCheap, light and portableLow capacity, slow, scratches easily
Solid stateSSD, USB stick, SD cardFast, no moving parts so durable, quiet, portableMore expensive per GB, smaller capacity for the price

Compare using: capacity, speed, portability, durability, reliability, cost. Example: a school backing up lots of work could use an external hard drive for its large capacity and low cost. A phone uses solid state because it is small, fast and durable.

1.2.4 How data is stored

Numbers

Tap the bits to build a binary number. Each bit is worth double the one to its right.

  • Hexadecimal (base 16) uses 0-9 then A=10, B=11, C=12, D=13, E=14, F=15. Each hex digit = one nibble (4 bits), so it is a shorter way to write binary. Example: 1111 0011 = F3.
  • Binary addition: 0+0=0, 0+1=1, 1+1=10 (write 0, carry 1), 1+1+1=11 (write 1, carry 1). An answer that needs more bits than are available is an overflow error.
  • Binary shift: a left shift by 1 multiplies by 2. A right shift by 1 divides by 2. Empty places are filled with 0s.

Characters

Each character has a binary code in a character set. ASCII uses 7 bits (128 characters, mainly English). Unicode uses more bits per character, so it covers many languages and symbols such as emojis, but files are bigger.

Images

  • An image is a grid of pixels, each stored as binary.
  • Resolution = width x height in pixels. Colour depth = bits per pixel. More of either means better quality but a bigger file.
  • Metadata is data about the file, such as dimensions, colour depth and date.
  • File size (bits) = width x height x colour depth

Sound

  • Sound is sampled: the wave's height is measured at regular intervals and stored in binary.
  • Sample rate (Hz) = samples per second. Bit depth = bits per sample. More of either means better quality but a bigger file.
  • File size (bits) = sample rate x bit depth x length in seconds

Compression

LossyLossless
Permanently removes some data. Much smaller file, quality drops, original cannot be restored. Example: JPEG, MP3.Reduces file size without losing any data. Original can be restored exactly. Smaller saving. Example: PNG, ZIP.

Describe the role of the ALU.2 marks
Mark points (any two):
  • Carries out arithmetic calculations, for example addition.
  • Carries out logical operations or comparisons, for example AND, OR, NOT.
  • Results are stored in the accumulator.
Describe the fetch-decode-execute cycle.4 marks
Mark points (any four):
  • The address of the next instruction is held in the PC.
  • The address is copied to the MAR.
  • The instruction is fetched from RAM at that address into the MDR.
  • The PC is incremented.
  • The Control Unit decodes the instruction.
  • The instruction is executed, for example the ALU performs a calculation.
  • The cycle repeats.
A computer has a 3.2 GHz quad-core CPU. Explain what this means.3 marks
Mark points:
  • 3.2 GHz means 3.2 billion fetch-decode-execute cycles per second.
  • Quad-core means the CPU has four cores (processing units).
  • So it can process several instructions at the same time, if the software supports it.
Explain how increasing the cache size can improve CPU performance.2 marks
Mark points:
  • More frequently used data and instructions can be stored in the cache.
  • Cache is faster than RAM, so the CPU spends less time waiting for data from RAM.
Explain why a CPU with more cores may not make a program run faster.2 marks
Mark points:
  • The program may not be written to split its tasks across several cores.
  • So only one core is used and the other cores sit idle (or the tasks depend on each other's results).
Give two characteristics of an embedded system.2 marks
Mark points (any two):
  • Performs a dedicated / specific function.
  • Program stored in ROM (firmware).
  • Small, low power, low cost.
  • Limited or no user interface.
  • Often works in real time.
State two differences between RAM and ROM.2 marks
Mark points (any two):
  • RAM is volatile, ROM is non-volatile.
  • RAM can be read and written, ROM is read only.
  • RAM holds programs and data in use, ROM holds the bootstrap.
Explain what virtual memory is and why it is needed.3 marks
Mark points:
  • Part of secondary storage is used as if it were RAM.
  • It is needed when RAM is full.
  • Data not currently needed is moved out of RAM, then moved back when required (slower than RAM).
A school wants to back up students' work. Suggest a suitable storage device and justify your choice.3 marks
Mark points:
  • Identify a suitable device, for example an external hard disk drive (magnetic).
  • Large capacity, so lots of work fits.
  • Cheap per GB (or reliable and re-writable).
An image is 100 pixels wide and 50 pixels high, with a colour depth of 8 bits. Calculate its file size in bytes.2 marks
Mark points:
  • 100 x 50 x 8 = 40,000 bits.
  • 40,000 / 8 = 5,000 bytes.
A microwave oven contains an embedded system. Describe what it does and why it is not a general-purpose computer.3 marks
Mark points:
  • It controls the microwave, for example timer, power level, turntable and door sensor.
  • It only performs this one dedicated function.
  • It cannot be used to run other programs, unlike a general-purpose computer.
